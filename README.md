
# Food Fusion

Food Fusion is a PHP-based web application focused on recipes and culinary learning. It allows users to explore recipes, manage their cookbook, and access culinary and educational resources.

## ✨ Features

- Browse and explore recipe collections
- Add and edit recipes
- Manage personal cookbooks
- Access culinary resources
- Explore educational resources
- Contact the Food Fusion team
- Admin dashboard for managing website content
- Recipe, community, and contact management for administrators
